# Studio i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every piece of Studio's own text — chrome, dialogs, toasts, help, and the editor documentation — translatable, and ship it in nine languages.

**Architecture:** A dependency-free runtime in `src/i18n/`: one JSON file per feature namespace per locale, English bundled as source and fallback, every other locale a lazily imported chunk. The locale is fixed for the lifetime of a page: `index.tsx` resolves it, loads it, and only then imports `App`, so the first frame is already translated and import-time `t()` calls see the right locale. Switching language flushes pending autosaves and reloads.

**Tech Stack:** React 19, Bun (bundler, `bun test`), TypeScript 5.9 (compiler API for the scanner), `Intl.PluralRules` / `Intl.NumberFormat` / `Intl.DateTimeFormat`, Radix dropdown menu, next-themes.

**Spec:** `docs/superpowers/specs/2026-09-29-i18n-design.md`

## Amendments to the spec, found while planning

1. **ASM directive docs are editor documentation too.** `features/asm-editor/code-editor/language-definitions/directives.ts` (`AsmDirectiveDocs`, `ProgramProperties`) feeds the ASM hover and moves to `editor-docs.json` under `asm`.
2. **Test-runner output stays English.** `features/testbed/runner/*` runs in a separate Worker bundle (`build.ts:172`) that never boots a locale; its assertion and failure messages are runtime output, like compiler messages. The testbed *UI* is translated.
3. **Key types are generated.** JSON imports type every leaf as `string`, so `{param}` placeholders cannot be read at the type level. `scripts/i18n-types.ts` writes `src/i18n/keys.generated.ts` from the English JSON; a test fails when it is stale.
4. **The typecheck baseline is not clean.** `bunx tsc --noEmit -p .` reports 25 errors in `src/` today (missing `monaco-editor` / `lodash` types, one `@signumjs/wallets` export). Every task's gate is **no new errors**: the count stays at 25.
5. **The splash shows the current `logo.webp`.** The new mark ("Register", chosen 2026-09-29) is refined separately; swapping it in is a one-file change to `index.html` and `logo.webp`.

## Global Constraints

- Locales: `en` (source, fallback, bundled), `de`, `pt-BR`, `fr`, `es`, `it`, `uk`, `ru`, `zh-CN`.
- `localStorage` key for the chosen locale: `studio.locale`. next-themes' key: `theme`, default climate `nexus`.
- Namespaces (file names): `common`, `home`, `project`, `workflow`, `simulator`, `testbed`, `smartc-editor`, `asm-editor`, `editor-docs`.
- Key syntax: `"<namespace>.<path>.<leaf>"`, segments `[A-Za-z0-9_-]+`; placeholders `{name}` with `name` matching `\w+`; rich-text tags `<name>…</name>`, one level, no attributes.
- Plural leaves are objects whose keys are CLDR categories (`zero one two few many other`) and must contain `other`; selected by `count`.
- Never translated: SIGNA, Signum, SmartC, AT, product names, API function names, opcodes, directive names, file extensions, climate names (Nexus, Dawn, Solaris, Terminal), anything in backticks.
- Compiler messages, assembler messages and test-runner (Worker) messages stay English.
- No new runtime dependencies.
- Components call `t()` during render, never at module top level. The only import-time use is `language-definitions/*`.
- Splash: visible only after a 150 ms delay; breathes while visible; still under `prefers-reduced-motion: reduce`.
- A locale joins `LOCALES` only in the commit that completes its translation; the picker is hidden while `LOCALES` has fewer than two entries.
- Tests: `cd apps/studio && bun test` — 638 pass today; none may break. Typecheck: `cd apps/studio && bunx tsc --noEmit -p . 2>&1 | grep "error TS" | grep -v node_modules | wc -l` → `25`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A stored locale that no longer exists** (`studio.locale = "fr"` before French ships, or garbage) must fall through to the browser languages and then English, never crash or show raw keys. → Task 4 test.
2. **A plural object missing the active locale's category** (a Russian leaf without `few`) must use that locale's `other`, not jump to English. → Task 1 test.
3. **A parameter value that looks like markup** (`<T>` with a file name `"<code>x</code>"`) must render as literal text, never as an element. → Task 3 test.
4. **A locale chunk that fails to load** (offline, or a stale tab after a deploy renamed the hashed chunk) must boot in English, not leave the splash up forever. → Task 4 test.
5. **A pending save that throws** during a language switch must not block the reload. → Task 6 test.

`apps/studio/src/i18n/flatten.ts`:
```ts
import type { Messages } from "./runtime";

const PLURAL_CATEGORIES = new Set(["zero", "one", "two", "few", "many", "other"]);

/** A leaf whose keys are all CLDR plural categories, `other` among them. */
export function isPluralNode(node: unknown): node is Record<string, string> {
  if (typeof node !== "object" || node === null) return false;
  const keys = Object.keys(node);
  return (
    keys.length > 0 &&
    keys.every((k) => PLURAL_CATEGORIES.has(k)) &&
    typeof (node as Record<string, unknown>).other === "string"
  );
}

/** `{ a: { b: "x" } }` → `a.b → "x"`. Plural objects stay whole. */
export function flattenMessages(
  tree: Messages,
  prefix = "",
  out = new Map<string, string | Record<string, string>>(),
): Map<string, string | Record<string, string>> {
  for (const [key, node] of Object.entries(tree)) {
    const path = prefix ? `${prefix}.${key}` : key;
    if (typeof node === "string" || isPluralNode(node)) out.set(path, node);
    else flattenMessages(node, path, out);
  }
  return out;
}
```

`apps/studio/src/i18n/runtime.ts`:
```ts
import en from "./locales/en";
import { isPluralNode } from "./flatten";
import type { LocaleId } from "./locales";

/**
 * The locale is fixed for the lifetime of the page: `boot.ts` sets it once,
 * before `App` is imported. That is why `t()` is a plain function and not a
 * hook — Monaco providers, toasts and module-level docs can all call it.
 */

export type Messages = { readonly [key: string]: string | Messages };
export type Params = Record<string, string | number>;

let locale: LocaleId = "en";
let messages: Messages = en;

export function setMessages(id: LocaleId, next: Messages): void {
  locale = id;
  messages = next;
}

export function resetMessages(): void {
  setMessages("en", en);
}

export function activeLocale(): LocaleId {
  return locale;
}

function lookup(tree: Messages, key: string): string | Messages | undefined {
  let node: string | Messages | undefined = tree;
  for (const part of key.split(".")) {
    if (node === undefined || typeof node === "string") return undefined;
    node = node[part];
  }
  return node;
}

function select(
  node: string | Messages | undefined,
  params: Params | undefined,
  forLocale: string,
): string | undefined {
  if (typeof node === "string") return node;
  if (!isPluralNode(node)) return undefined;
  const count = params?.count;
  if (typeof count !== "number") return node.other;
  const category = new Intl.PluralRules(forLocale).select(count);
  return node[category] ?? node.other;
}

/** The template for `key` — active locale first, then English. */
export function rawMessage(key: string, params?: Params): string | undefined {
  return (
    select(lookup(messages, key), params, locale) ??
    select(lookup(en, key), params, "en")
  );
}

export function interpolate(template: string, params?: Params): string {
  if (!params) return template;
  return template.replace(/\{(\w+)\}/g, (match, name: string) =>
    params[name] === undefined ? match : String(params[name]),
  );
}

/** Untyped core of `t()`. Missing everywhere → the key itself. */
export function translate(key: string, params?: Params): string {
  const template = rawMessage(key, params);
  return template === undefined ? key : interpolate(template, params);
}

export function formatNumber(
  value: number,
  options?: Intl.NumberFormatOptions,
): string {
  return new Intl.NumberFormat(locale, options).format(value);
}

export function formatDate(
  value: Date | number,
  options?: Intl.DateTimeFormatOptions,
): string {
  return new Intl.DateTimeFormat(locale, options).format(value);
}
```

`apps/studio/scripts/i18n-types.ts`:
```ts
#!/usr/bin/env bun
/**
 * Writes src/i18n/keys.generated.ts from the English messages. JSON imports
 * type every leaf as `string`, so the placeholders a key needs are only
 * knowable by reading the text — which is what this does.
 */
import path from "path";
import { flattenMessages } from "../src/i18n/flatten";
import type { Messages } from "../src/i18n/runtime";

const PLACEHOLDER = /\{(\w+)\}/g;

function placeholders(text: string): string[] {
  return [...text.matchAll(PLACEHOLDER)].map((m) => m[1]);
}

export function generateKeyTypes(tree: Messages): string {
  const lines: string[] = [];
  for (const [key, leaf] of flattenMessages(tree)) {
    const isPlural = typeof leaf !== "string";
    const texts = isPlural ? Object.values(leaf) : [leaf];
    const names = [...new Set(texts.flatMap(placeholders))].filter(
      (n) => !(isPlural && n === "count"),
    );
    names.sort();
    const fields = [
      ...(isPlural ? ["count: number"] : []),
      ...names.map((n) => `${n}: string | number`),
    ];
    const type = fields.length ? `{ ${fields.join("; ")} }` : "undefined";
    lines.push(`  ${JSON.stringify(key)}: ${type};`);
  }
  return (
    "// GENERATED by scripts/i18n-types.ts from locales/en — do not edit.\n" +
    "// Run `bun run i18n:types` after changing an English JSON file.\n\n" +
    "export type MessageParams = {\n" +
    lines.join("\n") +
    (lines.length ? "\n" : "") +
    "};\n\n" +
    "export type MessageKey = keyof MessageParams;\n"
  );
}

if (import.meta.main) {
  const { default: en } = await import("../src/i18n/locales/en");
  const out = path.join(import.meta.dir, "../src/i18n/keys.generated.ts");
  await Bun.write(out, generateKeyTypes(en));
  console.log(`wrote ${path.relative(process.cwd(), out)}`);
}
```

```ts
export type RichPart = string | { tag: string; text: string };

const TAG = /<(\w+)>([\s\S]*?)<\/\1>/g;

/**
 * Splits `<tag>…</tag>` spans out of a translated template. Only the names in
 * `tags` count; anything else stays literal text. Nothing is parsed as HTML.
 */
export function splitRich(template: string, tags: readonly string[]): RichPart[] {
  const parts: RichPart[] = [];
  let last = 0;
  let pending = "";
  for (const match of template.matchAll(TAG)) {
    const [whole, tag, text] = match;
    if (!tags.includes(tag)) continue;
    pending += template.slice(last, match.index);
    if (pending) parts.push(pending);
    pending = "";
    parts.push({ tag, text });
    last = match.index! + whole.length;
  }
  pending += template.slice(last);
  if (pending) parts.push(pending);
  return parts;
}
```

```ts
import { LOCALES, STORAGE_KEY, type LocaleEntry, type LocaleId } from "./locales";
import { resetMessages, setMessages } from "./runtime";

const baseOf = (tag: string) => tag.split("-")[0].toLowerCase();

/**
 * Stored choice if still offered → first browser language that matches
 * (exactly, then by base language: pt-PT → pt-BR, zh-TW → zh-CN) → English.
 */
export function resolveLocale(
  stored: string | null,
  languages: readonly string[],
  available: readonly LocaleId[] = LOCALES.map((l) => l.id),
): LocaleId {
  const known = available.find((id) => id === stored);
  if (known) return known;
  for (const lang of languages) {
    const exact = available.find((id) => id.toLowerCase() === lang.toLowerCase());
    if (exact) return exact;
    const byBase = available.find((id) => baseOf(id) === baseOf(lang));
    if (byBase) return byBase;
  }
  return "en";
}

/** Loads `id` and makes it the page's locale. Never throws; English is the floor. */
export async function activate(
  id: LocaleId,
  entries: readonly LocaleEntry[] = LOCALES,
  root: { lang: string } = document.documentElement,
): Promise<LocaleId> {
  const entry = entries.find((e) => e.id === id);
  if (entry && id !== "en") {
    try {
      const { default: messages } = await entry.load();
      setMessages(id, messages);
      root.lang = id;
      return id;
    } catch (error) {
      console.warn(`[i18n] could not load "${id}", continuing in English`, error);
    }
  }
  resetMessages();
  root.lang = "en";
  return "en";
}

function storedLocale(): string | null {
  try {
    return localStorage.getItem(STORAGE_KEY);
  } catch {
    return null;
  }
}

export function boot(): Promise<LocaleId> {
  return activate(resolveLocale(storedLocale(), navigator.languages ?? []));
}
```

```ts
/**
 * Saves that are waiting on a debounce. Anything about to throw the page away
 * — a language switch reloads it — flushes these first.
 */
const pending = new Set<() => unknown>();

export function registerPendingSave(flush: () => unknown): () => void {
  pending.add(flush);
  return () => pending.delete(flush);
}

export async function flushPendingSaves(): Promise<void> {
  const results = await Promise.allSettled([...pending].map((flush) => flush()));
  for (const r of results) {
    if (r.status === "rejected") console.error("[pending-saves] flush failed", r.reason);
  }
}
```

```ts
interface Deps {
  storage?: Pick<Storage, "setItem">;
  reload?: () => void;
  flush?: () => Promise<void>;
}

/** The locale is fixed per page load, so changing it means loading the page again. */
export async function switchLocale(id: LocaleId, deps: Deps = {}): Promise<void> {
  const {
    storage = localStorage,
    reload = () => location.reload(),
    flush = flushPendingSaves,
  } = deps;
  await flush();
  try {
    storage.setItem(STORAGE_KEY, id);
  } catch (error) {
    console.warn("[i18n] could not store the locale", error);
  }
  reload();
}
```

```ts
import { readdirSync } from "fs";
import path from "path";
import { flattenMessages } from "./flatten";
import type { Messages } from "./runtime";

export interface LocaleProblems {
  extra: string[];
  placeholders: string[];
  tags: string[];
  code: string[];
  plural: string[];
  missing: string[];
}

type Leaf = string | Record<string, string>;

const texts = (leaf: Leaf) => (typeof leaf === "string" ? [leaf] : Object.values(leaf));
const sortedMatches = (leaf: Leaf, re: RegExp) =>
  [...new Set(texts(leaf).flatMap((s) => [...s.matchAll(re)].map((m) => m[1] ?? m[0])))].sort();
const same = (a: string[], b: string[]) => a.length === b.length && a.every((x, i) => x === b[i]);

const PLACEHOLDER = /\{(\w+)\}/g;
const TAG = /<(\w+)>/g;
/** Fenced blocks first, so their content is not also read as inline spans. */
const CODE = /(```[\s\S]*?```|`[^`\n]+`)/g;

export function compareLocale(source: Messages, target: Messages): LocaleProblems {
  const src = flattenMessages(source);
  const dst = flattenMessages(target);
  const p: LocaleProblems = { extra: [], placeholders: [], tags: [], code: [], plural: [], missing: [] };
  for (const key of src.keys()) if (!dst.has(key)) p.missing.push(key);
  for (const [key, leaf] of dst) {
    const ref = src.get(key);
    if (ref === undefined) { p.extra.push(key); continue; }
    if (typeof ref !== typeof leaf || (typeof leaf !== "string" && typeof leaf.other !== "string")) {
      p.plural.push(key);
      continue;
    }
    if (!same(sortedMatches(ref, PLACEHOLDER), sortedMatches(leaf, PLACEHOLDER))) p.placeholders.push(key);
    if (!same(sortedMatches(ref, TAG), sortedMatches(leaf, TAG))) p.tags.push(key);
    if (!same(sortedMatches(ref, CODE), sortedMatches(leaf, CODE))) p.code.push(key);
  }
  return p;
}

const LOCALES_DIR = path.join(import.meta.dir, "locales");

/** Every locale folder on disk — also those not yet offered in `LOCALES`. */
export async function loadLocaleDirs(): Promise<Map<string, Messages>> {
  const out = new Map<string, Messages>();
  for (const entry of readdirSync(LOCALES_DIR, { withFileTypes: true })) {
    if (!entry.isDirectory()) continue;
    const mod = await import(path.join(LOCALES_DIR, entry.name, "index.ts"));
    out.set(entry.name, mod.default as Messages);
  }
  return out;
}
```

```ts
#!/usr/bin/env bun
/**
 * Lists user-facing text that is still hardcoded: JSX text, labelled JSX
 * attributes, toast messages and label-like object properties. A line (or the
 * line after a comment) containing `i18n-ignore` is skipped.
 */
import ts from "typescript";
import { readdirSync, readFileSync, statSync } from "fs";
import path from "path";

const ATTRIBUTES = new Set(["title", "label", "placeholder", "aria-label", "alt", "description", "tooltip"]);
const PROPERTIES = new Set(["title", "label", "description", "placeholder", "tooltip", "message"]);
/** Two letters in a row, in any script — excludes "·", "→", "42". */
const WORDY = /\p{L}{2,}/u;
/** Names that are never translated. */
const NEVER = new Set(["SmartC", "Signum", "SIGNA", "Studio", "Nexus", "Dawn", "Solaris", "Terminal"]);

export interface Finding { line: number; text: string }

export function scanSource(fileName: string, text: string): Finding[] {
  const kind = fileName.endsWith("x") ? ts.ScriptKind.TSX : ts.ScriptKind.TS;
  const sf = ts.createSourceFile(fileName, text, ts.ScriptTarget.Latest, true, kind);
  const lines = text.split("\n");
  const ignored = (line: number) =>
    lines[line]?.includes("i18n-ignore") || lines[line - 1]?.includes("i18n-ignore");
  const out: Finding[] = [];

  const report = (node: ts.Node, value: string) => {
    const v = value.trim();
    if (!WORDY.test(v) || NEVER.has(v)) return;
    const line = sf.getLineAndCharacterOfPosition(node.getStart(sf)).line;
    if (!ignored(line)) out.push({ line: line + 1, text: v });
  };
  const literal = (n: ts.Node | undefined): string | undefined =>
    n && (ts.isStringLiteral(n) || ts.isNoSubstitutionTemplateLiteral(n)) ? n.text
      : n && ts.isTemplateExpression(n) ? n.head.text + n.templateSpans.map((s) => s.literal.text).join(" ")
      : undefined;

  const visit = (node: ts.Node) => {
    if (ts.isJsxText(node)) report(node, node.text);
    else if (ts.isJsxAttribute(node) && ATTRIBUTES.has(node.name.getText(sf))) {
      const init = node.initializer;
      const v = init && ts.isJsxExpression(init) ? literal(init.expression) : literal(init);
      if (v !== undefined) report(node, v);
    } else if (ts.isJsxExpression(node) && ts.isJsxElement(node.parent)) {
      const v = literal(node.expression);
      if (v !== undefined) report(node, v);
    } else if (ts.isCallExpression(node) && /^toast(\.\w+)?$/.test(node.expression.getText(sf))) {
      const v = literal(node.arguments[0]);
      if (v !== undefined) report(node, v);
    } else if (ts.isPropertyAssignment(node) && PROPERTIES.has(node.name.getText(sf).replace(/["']/g, ""))) {
      const v = literal(node.initializer);
      if (v !== undefined) report(node, v);
    }
    ts.forEachChild(node, visit);
  };
  visit(sf);
  return out;
}

function* files(target: string): Generator<string> {
  if (statSync(target).isFile()) { yield target; return; }
  for (const e of readdirSync(target, { withFileTypes: true })) {
    const p = path.join(target, e.name);
    if (e.isDirectory()) {
      if (e.name === "node_modules" || e.name === "i18n" || e.name === "language-definitions" || e.name === "runner") continue;
      yield* files(p);
    } else if (/\.tsx?$/.test(e.name) && !/\.test\.tsx?$/.test(e.name) && !e.name.endsWith(".generated.ts")) {
      yield p;
    }
  }
}

if (import.meta.main) {
  const targets = process.argv.slice(2);
  let count = 0;
  for (const target of targets.length ? targets : ["src"]) {
    for (const file of files(target)) {
      for (const f of scanSource(file, readFileSync(file, "utf8"))) {
        console.log(`${file}:${f.line}  ${f.text}`);
        count++;
      }
    }
  }
  console.log(count ? `\n${count} hardcoded strings` : "clean");
  process.exit(count ? 1 : 0);
}
```

## Extraction tasks (9–16) — the shared procedure

Every extraction task follows the same procedure on its own set of files. It is written out once here and referenced by each task **together with that task's file list and namespace**; nothing else differs.

**Procedure for namespace `<ns>` over files `<FILES>`:**

1. Run `cd apps/studio && bun run i18n:scan <FILES>` and keep the output as the worklist. Also read each file: the scanner misses strings built in variables that are rendered later (e.g. `const msg = "…"; toast(msg)`, `throw new Error("…")` whose message reaches a toast, `confirm` dialog props passed through objects). Include those.
2. For each string, add a key to `src/i18n/locales/en/<ns>.json`. Key naming: `<component-or-area>.<purpose>` in camelCase — e.g. `newFileDialog.title`, `newFileDialog.nameLabel`, `toasts.saved`. Reuse `common.*` for words that mean the same everywhere (`common.actions.save`, `common.actions.cancel`, `common.actions.delete`, `common.actions.close`); add them to `common.json` the first time they are needed.
   - Dynamic text → placeholders: `` `Deleted ${name}` `` becomes `"deleted": "Deleted {name}"`.
   - Counts → plural objects: `` `${n} files` `` becomes `"files": { "one": "{count} file", "other": "{count} files" }`, called with `{ count: n }`.
   - Sentences with inline elements (`<code>`, `<a>`, `<b>`, `<kbd>`) → one key with tags, rendered with `<T k components={{ … }} />`. Never split a sentence into several keys.
   - Text passed to `toast.error("Could not save file: " + e.message)` → `"saveFailed": "Could not save file: {message}"`; the compiler/runtime message itself stays as passed.
3. Run `bun run i18n:types`.
4. Replace each string with `t("<ns>.…")` or `<T k="<ns>.…" … />`, calling `t()` inside the component/function body. Module-level arrays or objects that carry labels (`const ITEMS = [{ label: "New file" }]`) store the **key** instead (`{ labelKey: "project.menu.newFile" as const }`) and the render calls `t(item.labelKey)`.
5. Strings that must stay English get `// i18n-ignore` on the line above, with a reason in the same comment (e.g. `// i18n-ignore — product name`).
6. Gates, all must hold:
   - `bun run i18n:scan <FILES>` → `clean`
   - `bun test` → all pass (tests that assert on English UI text keep passing, because English is the default locale)
   - typecheck → `25`
   - `bun test src/i18n/keys.test.ts` → pass (generated types current)
7. Run the app (`run` skill) and click through the screens these files render; every text still reads as before.
8. Commit: `feat(studio): <ns> speaks through i18n` with the Co-Authored-By trailer.

**Key layout** (all under `editor-docs.`):
- `builtins.<name>.detail`, `builtins.<name>.doc`, `builtins.<name>.params.<param>` — `SmartCFunctions`
- `keywords.<name>.detail`, `keywords.<name>.doc`
- `directives.<directive>.detail|doc` and `directives.<directive>.properties.<prop>.detail|doc` — `SmartCDirectives` and its property tables
- `api.shared.registers|asNumber|timestamp|costs` — the shared prose constants in `api-functions.ts`

- `asm.<directive>.detail|doc`, `asm.program.properties.<prop>.detail|doc`

**Rules:**
- Empty English strings (e.g. `detail: ""`) stay literal `""` in code — no key.
- Signatures, snippets, `include`, arity and everything that is not prose stay in TypeScript.
- Markdown (code fences, `\n`, `*`) moves into JSON verbatim.
- Every call is a literal `t("editor-docs.…")` so the key is typed and statically visible.
